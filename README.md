# 🛒 Ejercicio 14 – Clases y Objetos Básicos en Java

## 📌 Descripción
Modelado de una tienda de productos usando los conceptos fundamentales
de la Programación Orientada a Objetos en Java.

## 🎯 Conceptos practicados
- Clases y objetos
- Atributos y constructores
- Métodos de instancia
- Getters y Setters
- Encapsulamiento básico
- ArrayList para colecciones simples

## 🚀 Cómo ejecutar
1. Clona el repositorio
2. Compila: javac src/*.java
3. Ejecuta: java -cp src Main

## 🛠️ Tecnologías
- Java 25
